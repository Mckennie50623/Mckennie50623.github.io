プライバシーポリシー

対象：Hermes Google Bridge ／ 更新日：2026-10-07

Hermes Google Bridge（以下「本アプリ」）は、個人運用者が自分のGoogleアカウントを管理するための連携ツールです。本ポリシーは、Google APIから取得するデータと、本説明サイトにおける取扱いを説明します。

1. 取得する情報

  • 認証したGoogleアカウントのメールアドレス、OAuthアクセストークン・更新トークン。
  • GmailのメッセージID、スレッドID、変更履歴ID、ラベル、フィルタ設定。利用者がメール検索・読み取りを依頼した場合は、検索結果とメール情報（ヘッダー、本文等）。
  • Googleカレンダーの一覧、予定情報。予定情報にはタイトル、日時、場所、説明、参加者情報等が含まれる場合があります。
  • 受信・再試行・重複排除のためのイベントID、処理状態、最小限の運用ログ。

実際に取得する情報は、利用者の依頼、承認済みルール、許可されたGoogle権限の範囲によって異なります。現在の自動受信経路はメールID等の候補記録と接続確認のみで、メール本文の自動取得は行いません。

2. 利用目的と制限

データは、利用者向けのメール確認・整理、フィルタ管理、予定管理、依頼に基づくノート記録、およびこれらの連携の安全な運用に使用します。広告配信、データ販売、利用者と無関係な目的には使用しません。

本アプリの運用者は、Google APIから取得したデータを、汎用AIモデルの開発・改善・学習に使用しません。本アプリによるGoogle APIから受け取った情報の使用および他のアプリへの転送は、Limited Use要件を含むGoogle API Services User Data Policyに従います。

3. AIサービス・他サービスへの送信

Hermes AgentのAI機能を利用するため、処理に必要なデータが運用者の設定する外部AI推論サービスに送信されることがあります。現在の自動接続確認では、アカウント識別名、イベントID、メッセージID、履歴ID等をAIへの入力に含めます。利用者が要約や抽出を依頼した場合は、その処理に必要な本文や予定情報を含むことがあります。

使用するAI提供者・モデルは実行環境の設定により変更されます。提供者のデータ保持・セキュリティ条件は、それぞれの適用される契約・ポリシーに従います。運用者は、Googleユーザーデータの取扱いがGoogleのLimited Use要件に適合する提供条件で処理する必要があります。

Google Cloud Pub/SubはGmail変更通知の配送に使用します。利用者がノートへの記録を許可した場合、必要な情報を個人のObsidian Vaultへ保存し、そのVaultで設定された端末間同期の対象になることがあります。認証情報はVaultに保存・同期しません。

機能提供、安全対策、法令対応を除き、取得データを第三者へ提供しません。人がデータを閲覧するのは、利用者の同意、安全対策・障害調査、法令対応など、GoogleのLimited Use要件で許容される場合に限ります。

4. 保存と保護

認証情報は運用者管理の非公開実行環境に、ファイルアクセス権を制限して保存します。Vault、Gitリポジトリ、公開サイトには保存しません。現在の認証ファイルはアプリ独自の暗号化ではなく、OSのアクセス制御で保護しています。

処理候補・重複排除情報は非公開のローカルデータベースに保存します。Google APIとの通信はTLSを利用します。内部の受信候補連携はloopback接続と署名認証を使い、公開の受付URLを必要としません。

候補記録・運用ログには現在、自動削除の保存期限を設けていません。継続運用に必要な間保持し、利用者の依頼や運用方針に基づいて削除します。バックアップやチャット履歴等に別コピーがある場合は、各保存先でも削除・管理が必要です。

5. アクセス許可の取消し・削除

利用者は、Googleアカウントの接続管理で、本アプリのアクセス許可を取り消せます。ローカルの認証情報、処理記録、ノート等の削除は、運用者へ依頼するか、自分の実行環境で実施してください。アクセス許可の取消しだけで、すでに保存した情報が自動的に削除されるわけではありません。

Pub/Sub受信用のサービスアカウント鍵は、Google Cloud側で個別に失効できます。OAuthの取消しとは別の操作です。

6. この説明サイト

このサイトには独自のアクセス解析、広告、入力フォーム、認証機能、追跡スクリプトを設置していません。Googleユーザーデータを受け取る機能はありません。

GitHub Pagesで公開した場合、GitHubはセキュリティ目的で訪問者のIPアドレス等を記録します。詳細はGitHubのプライバシーステートメントを参照してください。

7. お問い合わせ・変更

運用者は本アプリを個人利用するGitHubリポジトリ所有者です。お問い合わせはサイトのGitHub Issuesへお願いします。公開の問い合わせ欄には個人情報や認証情報を投稿せず、機密情報の相談は運用者と個別に調整してください。

取得項目やデータの利用・共有方針に変更がある場合、本ページを更新し、必要に応じて利用者へ案内・再同意を求めます。
